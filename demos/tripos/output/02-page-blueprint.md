# TripOS landing page: blueprint and component map

| # | Section | Module | Components (tripos.css) |
|---|---|---|---|
| 1 | Header | Sticky board bar | `wordmark`, `btn--flap` |
| 2 | Hero | Type left, board right, anchored bottom | `display`, `lede`, `btn--flap`, `btn--ghost`, `board` (split-flap) |
| 3 | The problem | Statement paragraph, 3/9 split | `label`, statement, inline mono sources |
| 4 | What we're building | Index rows with giant words | `section-head`, `feature` rows |
| 5 | Semester abroad | Full-bleed yellow band, three columns on hairlines | The one yellow surface |
| 6 | The pilot | Dark panel behind the conversion, 5/7 split | `btn--flap`, `text-link`, `ledger` |
| 7 | Footer | The CTA is the headline | `display`, `btn--ink`, `wordmark` |

Motion register: **kinetic**. Masked headline rise, split-flap board characters, one disruption status flip, scroll reveals. One curve: `cubic-bezier(.16,1,.3,1)`; flap uses `cubic-bezier(.77,0,.18,1)`. All gated behind `.motion` with a reduced-motion override.

Brochure: generated by `demos/tripos/brochures/build.js` from a trip file. Four sheets: cover ticket, one board, plan B, know before you land. Self-contained (fonts embedded), Letter print CSS.
