For builders

Make a brochure.

  1. 01Download the pilot form responses as a .csv and turn them into draft trip files.
    npm run brochure:intake -- responses.csv
  2. 02Fill in each trip file in demos/tripos/brochures/data/, or ask Claude: “make Maya’s brochure”. The trip-brochure skill researches the destination and fills the TODOs.
  3. 03Build it. Real brochures land in brochures/out/, which never goes online.
    npm run brochure -- demos/tripos/brochures/data/maya-paris.json
  4. 04Open it, press Print, save as PDF, and send it.
