# Phase 02 - Research

## Purpose
Understand the current state and gather visual/content references.

## Inputs
- Intake summary from Phase 01
- Structured intake data (`intake/answers.json` — see `reference/intake-contract.md`)
- Current website URL
- Competitor/reference sites

## Process
1. Crawl current website
   - Capture screenshots at multiple viewports
   - Extract existing copy and messaging
   - Identify current navigation structure
   - Note what's working well

2. Research competitors and references
   - Screenshot competitor sites
   - Analyze visual patterns
   - Document differentiators

3. Create inventory
   - Visual elements to keep (the brand's real equity — a logo finish, a color, a photo set)
   - Copy/messaging to preserve, with the source page for every line
   - Hyper-specific nouns worth surfacing (equipment models, places, years, named clients, counts)
   - Data conflicts between pages (flag them; never pick silently)
   - Elements to replace or improve, and why
   - Missing elements to add (as open items with owners — never invent proof)

4. Find the concept (see `docs/DESIGN-CRAFT.md` §1–2)
   - One sentence naming the idea, sourced from the client's own story, trade, words or product —
     never from a mood board. Examples: Element 47's name origin ("Forty-seven"), Omni's "machines
     steel to tight tolerances", Wilson & Walker's own byline "The Curated Surface", IntualityAI's
     "we predict what happens next".
   - Start the rationale table: *device → where it comes from*. Phase 03–04 add rows; nothing ships
     without one.
   - Pick the motion register the concept implies (Mechanical / Editorial-slow / Kinetic).
   - Curate the image inventory by position: mark weak real photos as cut (with the reason and an
     owner), rather than letting availability decide the hero.

## Outputs
- `output/02-research.md`
  - Current site analysis
  - Competitor analysis
  - Visual inventory
  - Copy inventory
  - Recommendations
  - **Concept** sentence, rationale table, motion register, image cut-list

- `output/02-screenshots/`
  - Current site screenshots
  - Competitor screenshots
  - Reference site screenshots

## Exit Criteria
- Complete site audit documented
- All screenshots captured
- A concept sentence with a sourced rationale table, a motion register, and an image cut-list
- Clear recommendations for Phase 03 — advances automatically, no approval pause
